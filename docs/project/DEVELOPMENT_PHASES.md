## Phase 1: 比較レポート生成

**現在地:** 基本設計段階。詳細設計・実装は未着手。

### 目的

同一原本 PDF から生成された複数 MusicXML を比較し、人間が確認すべき箇所を絞り込むための比較レポートを生成する。

### 対象

- 複数 MusicXML の入力管理
- 各 MusicXML の単体構造検査
- 比較前の正規化
- 比較可能性の判定
- 差分比較
- 一致箇所、要確認箇所、比較不能箇所の分類
- 記譜上の高リスク領域の抽出
- 比較レポートの生成

### 終了点

```text
比較レポートの生成
```

### Phase 1 で行わないこと

Phase 1 の対象外は [PROJECT_SCOPE.md](PROJECT_SCOPE.md) を参照。以下は将来検討事項であり、現段階では実施可否を確定しない。Phase 1 と混同しないこと。

- 原本 PDF との照合
- 採用元の選択、手修正、統合
- Web UI、横並び比較画面

## 現行プロトタイプとの関係

`prototype/src/verify_score.py` は、単一 MusicXML の構造検査が技術的に可能かを確認するためのプロトタイプである。

- Phase 1 の正式実装ではない
- 現段階では改修しない
- 詳細設計後に、再利用、置換、廃止のいずれとするか判断する

Phase 1 の設計対象は複数 MusicXML の比較であり、現行プロトタイプの単一 MusicXML 検証とはスコープが異なる。
