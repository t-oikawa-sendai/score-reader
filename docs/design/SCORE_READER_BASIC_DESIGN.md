# verify_score.py プロトタイプ プログラム仕様書

## 対象プログラム

| 項目 | 内容 |
|------|------|
| ファイル | `prototype/src/verify_score.py` |
| 種別 | 技術検証用プロトタイプ（正式完成版ではない） |
| 依存 | `music21==10.3.0`（`prototype/requirements.txt` 参照） |

## テストプログラムの目的

`verify_score.py` は、OMR 出力 MusicXML に対する下流検査を技術的に可能か確認するためのテストプログラム（プロトタイプ）である。

- OMR（画像→MusicXML 変換）後の MusicXML を、推測せず書かれた内容どおりに読み取る
- 誤りが混入しやすい箇所を機械的に検査する
- 単一 MusicXML に対する検査手法の有効性を検証する

正式完成版ではない。現段階では改修対象としない。

## 入力

| 項目 | 内容 |
|------|------|
| 形式 | MusicXML ファイル（`.musicxml` 等、`music21.converter.parse` が読み込める形式） |
| 個数 | 1 ファイル |
| 指定方法 | コマンドライン第 1 引数 `input` |

入力ファイルは読み取り専用で扱う。プログラムは入力 MusicXML を変更しない。

## 出力

### 人間可読形式（デフォルト）

標準出力に、検査 [1]〜[8] の結果をテキストで出力する。

出力レベルの例:

| レベル | 意味 |
|--------|------|
| `[FATAL]` | パース失敗。処理を中断し終了コード 1 で終了 |
| `[ANOMALY]` | 小節長と拍子の不一致など、構造上の異常 |
| `[WARN]` | 要確認の疑い（拍子未確定、リハーサルマーク異常、和音音数の相違、パート間小節数不一致など） |
| `[INFO]` | 参考情報（単音が和音として記譜、無音高要素の件数など） |
| 通常行 | 検出結果の列挙 |

人間可読形式での出力順序は [1] → [2] → [3] → [4] → [6] → [7] → [8] → [5] である。

### JSON 形式（`--json` 指定時）

標準出力に、検査 [1]〜[8] の結果を構造化 JSON で出力する。

トップレベルの主なフィールド:

| フィールド | 内容 |
|------------|------|
| `parts` | パート数 |
| `transposing_instruments` | [1] 移調楽器情報 |
| `measure_anomalies` | [2] 小節長異常（WARN / ANOMALY のみ） |
| `key_signatures` | [3] 調号 |
| `tempo_meter_events` | [4] 拍子・テンポ変化イベント |
| `rehearsal_marks` | [6] リハーサルマーク |
| `chord_voicing` | [7] 和音音数 |
| `unreadable` | [5] 未確定要素 |
| `part_measure_counts` | [8] パート間小節数整合 |
| `warnings` | 全セクションの WARN / ANOMALY を集約した配列 |
| `note` | 検査の限界に関する注記 |

## 環境構築

```bash
cd <score-reader-repository-root>

python3 -m venv .venv
```

### 仮想環境の有効化

```bash
source .venv/bin/activate
```

```bash
pip install -r prototype/requirements.txt
```

依存ライブラリは `music21==10.3.0` のみである（`prototype/requirements.txt` 参照）。

## 実行方法

仮想環境を有効化した状態で、`prototype/src` へ移動して実行する。

```bash
cd prototype/src
```

### 人間可読形式（デフォルト）

```bash
python3 verify_score.py ../tests/<file>.musicxml
```

### JSON 形式

```bash
python3 verify_score.py ../tests/<file>.musicxml --json
```

### 実行対象 MusicXML の指定方法

- 第 1 引数にファイルパスを指定する（絶対パス・相対パスいずれも可）
- `prototype/tests/` 配下のテスト素材を使う場合は `../tests/<file>.musicxml` と指定する
- テスト素材はパブリックドメインに限定する（著作権保護譜面はリポジトリへ登録しない）

### パース失敗時の扱い

MusicXML のパースに失敗した場合、`[FATAL]` メッセージを標準出力へ出力して終了コード 1 で終了する。入力ファイルは変更されない。

## 検査項目

本プロトタイプは、以下 8 項目を検査する。

### [1] 移調楽器チェック

各パートについて、移調楽器か否か、記音→実音の半音差を報告する。

- 移調情報があるパート: 移調楽器である旨、半音差、方向名を出力
- 移調情報がないパート: 実音楽器（C 管）または移調情報なしとして出力
- 移調楽器が 1 件も検出されない場合: OMR 元が移調情報を欠落させている可能性への注記を出力

### [2] 小節長の検算

各パートの各小節について、拍子記号に対する音価合計（四分音符単位）を検算する。

- 拍子記号が未確定の小節: `[WARN]`
- 期待音価と実測音価が不一致の小節: `[ANOMALY]`
- 小節 0 または 1 で、実測が期待より短い場合（アウフタクト）: 許容し異常としない

### [3] 調号

第 1 パート（`score.parts[0]`）から調号を列挙し、出現小節番号とシャープ/フラット数を出力する。

### [4] テンポ/拍子 変化イベント

第 1 パート（`score.parts[0]`）から、拍子記号とテンポ（メトロノームマーク）の変化を小節番号順に列挙する。

### [5] 未確定・要確認 要素

スコア全体から `Unpitched`（無音高）要素の件数を報告する。

列挙が無い場合でも完全無欠を保証しない旨を注記する。

### [6] リハーサルマーク対応表

全パートからリハーサルマークを収集し、小節番号との対応を出力する。

- パートをまたぐ同一マークは `(小節, 内容)` で重複排除する
- 検出ゼロ: 注記を出力
- 小節番号が未確定: `[WARN]`
- 内容が空: `[WARN]`
- 同一小節に複数マーク: `[WARN]`

### [7] 和音の音数チェック

各パートの和音（`chord.Chord`）について、構成音数を集計・報告する。

- パート内の音数分布と主流（最頻）音数を出力
- 単音が和音として記譜されている場合: `[INFO]`
- 主流音数と異なる和音: `[WARN]`
- 和音が 0 件: 注記を出力（和音の取りこぼし可能性）

「何音であるべきか」は推測せず、正誤は断定しない。

### [8] 複数パート間の小節数整合チェック

各パートの小節数を比較する。

- パートが 1 つのみ: 比較対象なしとして `[INFO]` を出力
- 全パートの小節数が一致: 一致結果を出力
- 不一致: `[WARN]` を出力（どのパートが正しいか、どの小節が欠落したかは断定しない）

## 検査できること

- MusicXML のパース可否
- 各パートの移調楽器情報の有無と半音差
- 拍子記号に対する小節内音価合計の不一致
- 拍子記号未確定小節の存在
- 第 1 パート上の調号の出現位置
- 第 1 パート上の拍子・テンポ変化イベント
- 無音高（`Unpitched`）要素の件数
- リハーサルマークの小節対応、空内容、重複
- 和音構成音数の分布と、パート内主流音数からの相違
- 複数パート間の小節数不一致

## 検査できないこと

本プロトタイプは、音価・拍子・移調の整合性検査であり、以下は判定しない。

- 音高の正誤（符頭位置、加線、臨時記号、オクターブ違いなど）
- 和音構成音数が原本譜と一致するかの断定
- パート間小節数不一致時に、どのパートが正しいか
- どの小節が欠落または過剰認識されたかの特定
- 原本 PDF / 紙譜との内容一致
- タイ、スラー、連符、装飾音、多声部、打楽器記譜の正誤
- 強弱記号、テキスト指示、アクセント等の欠落
- OMR が和音を単音化した場合など、音価・拍子を保ったままの取りこぼし
- `[WARN]` / `[ANOMALY]` が 0 件であることによる完全無欠の保証

検査結果に問題がなくても、最終的な正確性は原本譜との目視照合で担保する必要がある。

## 非破壊仕様

- 入力 MusicXML ファイルを読み取るのみで、上書き・更新・削除を行わない
- 派生 MusicXML や修正済みファイルを出力しない
- 検査結果は標準出力（テキストまたは JSON）への出力に限る

## 制約

| 項目 | 内容 |
|------|------|
| 入力数 | 1 MusicXML のみ（複数ファイルの一括比較は行わない） |
| 調号・拍子/テンポイベント | 第 1 パート（`score.parts[0]`）のみを参照 |
| 依存ライブラリ | `music21` 10.3.0 |
| 終了コード | パース成功時 0、パース失敗時 1 |
| 設計原則 | 推測しない。読めない・断定できない箇所は黙殺せず WARN 等として列挙する |
| 移調楽器 | 記音（written）と実音（sounding）を区別して報告する |

## 著作権・秘密情報の注意

- 著作権保護された譜面を GitHub 等の公開リポジトリへ登録しない
- リポジトリ上のテスト素材はパブリックドメインに限定する（`prototype/tests/` 参照）
- 外部 OMR サービスへ譜面を送信する場合は、利用規約と著作権条件を確認する
- API キー、トークン、秘密鍵、個人情報をソース、ログ、Git 管理対象へ含めない
- 本プロトタイプの出力は検査支援情報であり、楽譜内容の正確性を保証するものではない
